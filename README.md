# userscripts

Small browser tweaks, run with [Tampermonkey](https://www.tampermonkey.net/) or any userscript manager.

To install a script, open its install link with the extension enabled.
The manager picks up new versions from the same URL.

| Script | What it does | Install |
|---|---|---|
| GitHub notifications: tint finished | Tints merged and closed rows in the [notifications inbox](https://github.com/notifications) a faint purple, in light mode only, so open work stands out. | [install](https://raw.githubusercontent.com/mokagio/userscripts/main/github-notifications-tint.user.js) |
